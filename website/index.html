// The Ecosystem

Four planes.
Every one stands alone.

Task, Memory, Compute, and Tools — each a standalone product, composing only at explicit contract seams. No monorepo. No god object. No shared secret.

Release Candidate // Task Plane

AgentConnect

the control plane

A durable, operator-owned ledger for coding-agent work: launch, shell, audit, complete. A managed agent structurally cannot sign off on its own task.

“If it is not recorded, it did not happen.”

Release Candidate // Memory Plane

BrainConnect

trusted memory ledger

Agents propose memories. Only a human promotes them to trusted. The CLI makes zero model calls — a hard determinism boundary.

“Agents can only propose, never decide.”

Shadow Mode // Control Model

Control Model

the advisory brain

A 4B CPU-deployable model emitting strict JSON routing decisions. It advises and detects conflict; deterministic code keeps all authority.

“The model advises. Code decides.”

MVP // Compute Plane

ComputeConnect

compute control plane

Knows what compute exists, whether it's healthy, and whether a model will fit — then decides where work runs. Privacy is structural, default-deny.

“Will this fit? — answered honestly.”

MVP // Tool Plane

ToolConnect

tool governance

The missing layer: which tools exist, who may call them, and what happened. A fail-closed decision point with a tamper-evident, hash-chained audit.

“An error is a denial.”

Integration Preview // The Umbrella

Connect

where you start

One command brings the whole stack up healthy. Un-driftable docs generated from a pinned-commit lockfile. Standalone first, always.

“Every product works alone. None requires another.”

// Proof, Not Promises

We name the limits
out loud.

These products ship "what the tests do not prove" sections. So does this page. Here's what's real — and what we deliberately refuse to build.

control-model policy violations, adversarial set

What holds

  • Human-gated memory: nothing is trusted until a person promotes it.
  • A managed agent cannot mark its own task complete.
  • Tool decisions fail closed, into a tamper-evident hash-chained audit.
  • Privacy is default-deny: a missing tier can only narrow exposure.

What we will not build

  • No monorepo, no god object — products stay standalone.
  • No security sandbox marketed as one: this records a cooperative agent, it does not contain a hostile one.
  • No memory system where an agent decides what is true.
  • No claim of heterogeneous compute until it's actually proven.
